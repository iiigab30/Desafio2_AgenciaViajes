# Agencia de Viajes - Segundo Desafío Práctico DSM

**Alumno:** [Erika Gabriela Guevara Chicas]

## Descripción
Aplicación Android para la gestión de un catálogo de destinos turísticos de una
agencia de viajes. Cada agente tiene su propia cuenta y solo puede ver, editar
y eliminar los destinos que él mismo registró.

## Funcionalidades
- Login y Registro de usuarios con Firebase Authentication
- Catálogo de destinos (RecyclerView + CardView) filtrado por usuario
- Crear, editar y eliminar destinos turísticos (CRUD completo en Firestore)
- Validaciones: campos obligatorios, precio mayor a 0, descripción mínima de
  20 caracteres, imagen obligatoria
- Selección de imagen desde galería y almacenamiento local, con Glide para mostrarla
- Cierre de sesión

## Tecnologías utilizadas
- Kotlin + Android Studio
- Firebase Authentication
- Firebase Firestore
- Glide (carga de imágenes)
- RecyclerView + CardView
- View Binding
